# RPGame-System
Base documental versionada para RPG textual com múltiplos mundos. Versão inicial: 0.1.

Leia [ENGINE](SYSTEM/ENGINE.md), [NARRATOR](SYSTEM/NARRATOR.md) e [MEMORY-RULES](SYSTEM/MEMORY-RULES.md). Mundo disponível: [Word](Mundos/Word/WORLD.md).

Esta entrega organiza regras e registros; ainda não contém aplicativo, execução automática de IA ou sincronização automática com GitHub.
O mundo Word está em reconstrução: a história principal ainda precisa ser importada. Não continuar a narrativa até recuperar e validar seu ponto de parada.
O arquivo que ocupava Mundos/Word foi preservado sem alteração em [Word-original.txt](Mundos/Word/SOURCES/Word-original.txt). Outros RPGs deste repositório não são fontes deste mundo.
